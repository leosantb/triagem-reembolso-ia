Comparei regressão logística e floresta aleatória. Os F1-scores para fraude ficaram praticamente iguais (0,50 e 0,49). A floresta teve accuracy maior (0,79), mas esse valor equivale a classificar todos os casos como legítimos, já que 79% do conjunto de teste é legítimo. Escolhi a regressão logística porque ela detecta 70% das fraudes, contra 46% da floresta. Neste sistema, um caso marcado como suspeito vai para revisão humana em vez de ser negado, então deixar uma fraude passar custa mais do que revisar um caso honesto. Ela também é mais fácil de explicar.

Na primeira versão, os motivos exibidos para o atendente eram escritos por regras fixas, que só disparavam em casos extremos (3 ou mais reembolsos, 5 ou mais reclamações etc.). Isso gerava telas contraditórias: um caso aparecia como "Risco alto", mas o único motivo exibido era "A foto confirma o problema". O modelo tinha somado vários fatores moderados, como conta nova, 1 ou 2 reembolsos anteriores e pedido de valor alto, sem que nenhum deles passasse do limite das regras. Por isso, passei a tirar os motivos do próprio modelo. Na regressão logística, a contribuição de cada característica é o seu valor multiplicado pelo peso aprendido: contribuições positivas aumentam a suspeita e negativas reduzem. O sistema mostra as maiores contribuições, então os motivos sempre explicam a classificação que o atendente está vendo.

O resumo de cada caso é gerado localmente com o Ollama. Para deixar as respostas mais confiáveis, montei o prompt com algumas técnicas. Em vez de nomes técnicos de colunas, o modelo recebe os dados traduzidos em texto, como "pedido não entregue, de R$ 45,00, risco médio". As regras de escrita (português do Brasil, acentuação correta etc.) ficam no campo system, separadas dos dados do caso, e o prompt inclui um resumo pronto como exemplo de tom e formato (few-shot). Usei temperatura 0,2 para deixar as respostas mais previsíveis e deixei o score fora do prompt, para o modelo não errar nem inventar números. Por fim, o sistema confere cada resposta: se o texto vier longo demais ou com palavras em inglês, ele é descartado e o atendente recebe o resumo padrão. O LLM só resume o caso; a classificação vem sempre da regressão logística.
